# Tableau Public Dashboard — Global Retail Pulse

This dashboard visualizes the sales performance of a UK-based online retailer (Dec 2010 – Dec 2011), using the summary tables exported by `notebooks/01_exploratory_analysis.ipynb`.

## Data Sources

All source files live in `data/processed/` and are generated by the last cell of the exploratory analysis notebook:

| File | Contents |
| --- | --- |
| `tableau_monthly.csv` | Monthly aggregates — `year_month`, `total_revenue`, `total_orders`, `unique_customers` |
| `tableau_top_products.csv` | Top 20 products by total revenue — `Description`, `total_revenue` |
| `tableau_rfm.csv` | Full customer RFM table — `Customer ID`, `recency`, `frequency`, `monetary`, `segment` |
| `tableau_country.csv` | Revenue by country (all countries) — `Country`, `total_revenue` |

## Dashboard Sheets

1. **Revenue Trend** — Line chart built from `tableau_monthly.csv`, with `year_month` on the X axis and `total_revenue` on the Y axis. Shows overall business performance and seasonality over the year.
2. **Top Products** — Bar chart built from `tableau_top_products.csv`, with `Description` and `total_revenue`, filtered to the top 10 products. Highlights the best-selling items driving revenue.
3. **RFM Segments** — Bar chart built from `tableau_rfm.csv`, with `segment` and customer count, plus an optional treemap sized by `monetary` to show which segments hold the most value.
4. **Country Map** — Map chart built from `tableau_country.csv`, with `Country` and `total_revenue`, showing the geographic distribution of sales.

## How to Build

1. Open [Tableau Public](https://public.tableau.com/) and create a new workbook.
2. Connect to each of the 4 CSV files in `data/processed/` as separate data sources (Data → Connect to Data → Text File).
3. **Revenue Trend**: create a new sheet, drag `year_month` to Columns and `total_revenue` to Rows, set the mark type to Line.
4. **Top Products**: create a new sheet, drag `Description` to Rows and `total_revenue` to Columns, set the mark type to Bar, sort descending, and use a Top 10 filter on `Description` by `total_revenue`.
5. **RFM Segments**: create a new sheet, drag `segment` to Columns and use Count of records for Rows, set the mark type to Bar. Optionally duplicate as a treemap with `segment` on Detail/Color and `monetary` (sum) on Size.
6. **Country Map**: create a new sheet, drag `Country` to Detail (Tableau should auto-generate geographic roles) and `total_revenue` to Color, set the mark type to Map.
7. Combine all 4 sheets into a single Dashboard, arrange them in a grid, and add filters/titles as needed.
8. Publish the workbook to Tableau Public and copy the shareable link below.
